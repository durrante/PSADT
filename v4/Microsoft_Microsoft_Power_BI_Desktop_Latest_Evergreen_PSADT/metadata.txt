**Microsoft Power BI Desktop** is a free data analysis and report authoring tool developed by Microsoft. It is used to connect to data sources, transform and model data, and build interactive reports and dashboards that can be published to the Power BI service for sharing across the organisation.

## Key Features

* Connects to hundreds of data sources including Excel, SQL Server, Azure services, SharePoint, and web APIs
* Power Query editor for cleansing, shaping, and combining data before analysis
* Data modelling with relationships, calculated columns, and DAX measures
* Drag-and-drop report canvas with a wide range of interactive visualisations
* Publishing to the Power BI service for sharing reports and dashboards
* Custom visuals available through Microsoft AppSource
* Row-level security for controlling data access within reports
* Compatible with currently supported Windows operating systems (x64)
