				HOW TO MANAGE "Custom" sub-folder
			
1) Mandatory file(s)
- eSignerV6_x64_Preinstall.msi			

2) Optional file(s)
- local.conf (for eSigner 6.x customization)
- eSignerDialogs.xrc (for eSigner 6.x customization)
- Custom32.reg (x86 platform)
- Custom64.reg (x64 platform)

Note: CustomXX.reg file is intended to enable both Trusted Sites and some Key Registry entries (Classic Client)
